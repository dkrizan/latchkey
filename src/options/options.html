AutoLogin Rules

Credentials are stored in plain text. Rules live unencrypted in this browser profile's extension storage and are included as-is in exports. Use this for development, test and staging accounts, not for personal or production passwords. Encryption with a master password is planned.
Localhost access is not granted. Your browser did not grant access to localhost and 127.0.0.1 at install time, so local rules cannot run.
